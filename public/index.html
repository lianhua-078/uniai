常見問題

如何有效使用 UniAi？

UniAi 會直接用 AI 產生回答嗎？

會。此專案已包含 AI API 連接功能；完成伺服器與 API key 設定後，AI 助理便能直接回覆。若尚未設定 API key，其他任務導航與 Prompt 產生功能仍可使用。

推薦的工具一定是最好的嗎？

不一定。推薦只是依任務類型提供的起點，不代表絕對排名。工具的功能、價格、使用限制與資料政策可能變動，使用前請查看官方資訊。

可以讓 AI 幫我完成整份作業嗎？

建議把作業拆成理解題目、規劃、研究、分析、撰寫初稿與查證等小任務。用 AI 幫助自己學習與改善思考，不要直接繳交自己不理解或未查證的內容。

Prompt 越長就一定越好嗎？

不一定。好的 Prompt 應該有清楚目標、足夠背景、輸出要求與評估標準。遇到大型任務時，可以分階段進行，並根據每次結果調整要求。
